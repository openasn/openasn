# org_names.txt: ASN -> organization name. This file is the ONLY source of
# names in openasn-orgs.bin and the asn-categories.csv `org` column besides
# Wikidata (CC0). CC0, like every file here. See DECISIONS.md D-SRC-2 (org
# names).
#
# Why this file exists. Until 2026-09 the published names were ipverse
# as-metadata descriptions, which are bulk RIR WHOIS `descr`. APNIC, ARIN and
# RIPE forbid republishing WHOIS in bulk, and ipverse's CC0 cannot license
# data it does not own (AGENTS.md rule 1). Those names are now a Tier B
# recipe that clients fetch themselves (`ipverse_org_names` in
# fetch-manifest.json).
#
# Line format:  AS<number>  <name>  # src: <url> (<YYYY-MM-DD>)
#   * the name is everything between the ASN and " # "
#   * src must be a FIRST-PARTY page (the operator's own site or docs) or a
#     CC0/reference page (Wikidata, Wikipedia for the bare fact). A registry
#     or aggregator page (RIR WHOIS/RDAP, PeeringDB, bgp.he.net, CAIDA AS
#     Rank, ipinfo, db-ip, ipverse, ...) FAILS the build: a name resting on
#     WHOIS is exactly what D-SRC-2 took out of the core.
#   * write the operator's common name in your own words from the cited
#     source. Never paste a WHOIS `descr` or an ipverse description.
#   * precedence: this file > Wikidata P3797 labels > no name (as_org nil).
#
# Order of work (AGENTS.md rule 7): the head first. The two sections below
# cover 66.8% of APNIC-estimated eyeballs and 49.3% of routed IPv4 space
# together with Wikidata (measured 2026-09-19). The ranked gap list for the
# next pass is in the D-SRC-2 evidence record.
