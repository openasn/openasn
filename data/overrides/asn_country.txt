# asn_country.txt: ASN -> country (ISO 3166-1 alpha-2). This file is the ONLY
# source of the asn-categories.csv `country` column besides Wikidata (CC0).
# CC0, like every file here. See DECISIONS.md D-SRC-2 (country).
#
# Why this file exists. Until 2026-09 the published country was ipverse
# as-metadata `countryCode`, which ipverse sources "from regional internet
# registries (RIR)": registry data under the RIRs' terms, which ipverse's CC0
# cannot license (AGENTS.md rule 1; the same finding as the org names). The
# registry countries are now a Tier B recipe that clients fetch themselves
# (`ipverse_as_country` in fetch-manifest.json).
#
# Meaning. The country the ASN's operator is based in: its seat or
# headquarters. That is close to the registry country it replaces but not
# identical (a registry records the registrant's address).
#
# Line format:  AS<number>  <CC>  # src: <url> (<YYYY-MM-DD>)
#   * CC is an ISO 3166-1 alpha-2 code, upper case. XX/ZZ/EU/AP and other
#     non-country codes fail the build.
#   * src must be a FIRST-PARTY page (the operator's imprint, legal notice,
#     contact or about page) or a CC0/reference page (Wikidata, Wikipedia for
#     the bare fact). A registry or aggregator page (RIR WHOIS/RDAP/stats,
#     PeeringDB, bgp.he.net, CAIDA, ipinfo, db-ip, ipverse, ...) FAILS the
#     build: a country resting on registry data is exactly what D-SRC-2
#     (country) took out of the core.
#   * `--` instead of a code publishes NO country for the ASN and stops the
#     Wikidata fallback: `AS9002  --  # none: <why>; src: <url> (<date>)`.
#     Used for a Wikidata value we checked and found wrong, or a group item
#     linked to a subsidiary's ASN we cannot place.
#   * `territory: <key>` before src marks an operator in an occupied or
#     breakaway territory (CD-19a); the build requires the recognised
#     state's code (crimea/sevastopol/donetsk/luhansk/zaporizhzhia/kherson
#     -> UA, abkhazia/south_ossetia -> GE, transnistria -> MD,
#     northern_cyprus -> CY).
#   * precedence: this file > Wikidata (P17, else P159 -> P17, of the ASN's
#     admitted P3797 item) > no country (empty cell).
#
# Order of work (AGENTS.md rule 7): the head first. The ranked gap list for
# the next pass is in the D-SRC-2 (country) evidence record.
